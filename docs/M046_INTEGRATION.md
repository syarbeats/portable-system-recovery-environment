# M046 Integration
Prerequisites: xHCI running; device enumerated; M019 configuration and M020 configuration activation complete; `m044-init`; `m044-activate`.
Then run `m046-init`, followed by `m046-info`, `m046-inquiry`, `m046-ready`, and `m046-capacity`.
The CLI reports command-level success/failure. No block device is registered in M046.
