# Changelog — M036

- Added static application registry (8 slots) and registration descriptors.
- Added lifecycle states REGISTERED, RUNNING, STOPPED and ERROR.
- Added launch, focus/reuse, stop and window reconciliation APIs.
- Added focused-window event dispatch and per-app 64-byte state storage.
- Added label, button, textbox and checkbox immediate-mode drawing helpers.
- Integrated four M035 built-in application launchers with M036.
- Added `m036-info` CLI diagnostics and host tests.
