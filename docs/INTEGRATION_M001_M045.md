# PSRE Cumulative Integration M001–M045

Build 4.0 retains the cumulative M001–M044 tree and adds M045. The M044 MSC interface discovery now hands its Bulk IN/OUT endpoint addresses and packet sizes to M045 for xHCI endpoint configuration. M045 provides raw Bulk transfer APIs; M044 BOT orchestration, SCSI command execution over USB, block-device registration, USB FAT32 mounting, and File Explorer USB browsing remain future work.
