# PSRE Integrated Build 3.9 — M001–M044

This is the cumulative PSRE source tree through M043. All prior milestone sources and documentation from Build 3.7 (M001–M042) are retained.

M043 adds a cooperative recovery job manager, bounded serial export steps, progress counters, pause/resume, explicit retry, and a 16-record history. It integrates with M008/M009, the M041 Recovery Manager GUI, and the M035 polling command. Source FAT32 media remains read-only.

See `M043_SRS.md`, `M043_ARCHITECTURE.md`, `M043_TEST_PLAN.md`, `M043_INTEGRATION.md`, and `M043_BUILD_VALIDATION.md`.
