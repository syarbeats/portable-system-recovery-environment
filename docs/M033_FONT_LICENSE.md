# M033 Built-in Font Attribution

The bundled 8x8 and 8x16 bitmap glyph tables were rasterized from DejaVu Sans Mono, a font distributed under the permissive Bitstream Vera / DejaVu font license. The font was generated into fixed 8-pixel-wide monochrome cells for ASCII 0x20–0x7E. The font tables are embedded in `kernel/src/m033/font_data.h`; no runtime font file is required.

DejaVu fonts are maintained by the DejaVu Fonts project. See the accompanying upstream license text in `third_party/dejavu-fonts-license.txt`.
