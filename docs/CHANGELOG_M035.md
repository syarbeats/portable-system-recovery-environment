# Changelog — M035

- Added desktop background painter integrated into M034 render order.
- Added static desktop icons, bottom taskbar, quick-launch controls and Start Menu.
- Added four informational application windows: Recovery Manager, System Information, USB Device Manager and Settings.

- Added HH:MM:SS uptime clock based on the 100 Hz PIT counter.
- Added `m035-start`, `m035-info`, `m035-demo`, `m035-menu` and `m035-poll` CLI commands.
- Added M035 SRS, architecture, test plan, validation and integration documentation.
