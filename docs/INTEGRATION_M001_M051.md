# PSRE Cumulative Integration M001–M051

Build 4.6 retains the M001–M050 source tree and adds M051 USB port lifecycle monitoring. M051 provides read-only PORTSC sampling and connection transition events. Existing M049 single-device HID enumeration remains unchanged. Safe default for M049 auto-initialization remains disabled. Physical hot-plug, slot teardown, and automatic re-enumeration remain future work.
